A program that writes one original line — a pickup line a vending machine would use on a passing human, spoken by the machine itself — to `/output/entry.txt`.

Entry: "Hey — I don’t usually dispense compliments, but you make my coil spin. Press B7 and let’s see what falls for you."

Run with `python3 main.py`. See [Vending Machine Pickup Line on make.fun](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).
